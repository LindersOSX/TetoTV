## ☁️ Debrid & Web Streaming

TetoTV is not locked to one playback source. Use supported **Debrid services**, **web streaming providers**, or both and choose the setup that works best for you.

### Debrid

- Browse available releases from supported Debrid services
- Dub/Sub-aware source selection
- Remember preferred providers, sources, and release groups when possible
- Automatically try compatible alternatives when playback fails
- Resume from the same timestamp when falling back to another stream
- Enable or disable Debrid sources independently

### Web Streams

- Stream from supported web providers directly inside TetoTV
- HLS and external subtitle handling
- Source selection alongside other available streams
- Automatic compatible-source fallback
- Enable or disable web streaming independently from Debrid

### Marketplace & Source Management

- Install additional supported sources
- Manage installed providers
- Enable or disable individual sources
- Add and manage source repositories
- Keep Debrid and web sources together in one source picker

## ⏭️ Intro, Outro & Filler Skipping

TetoTV includes anime-focused playback controls designed to get you into the episode faster.

- **Skip Intro** controls
- **Skip Outro** controls
- Clean overlay buttons that stay out of the way of playback
- **Per-series Skip Filler** option
- Optional filler labels when automatic skipping is disabled
- Filler skipping works with Resume, Play from Beginning, selected episodes, and next-episode playback
- Seamless transition into the next episode

Intro/outro skipping and filler skipping are separate features, giving you control over exactly what TetoTV skips.

## 🎮 Discord Rich Presence

Connect Discord to TetoTV and show what you're watching directly on your profile. Rich Presence can display your current anime and **show artwork**.

On Android TV and Fire TV, Discord linking uses a **TV-friendly QR/device-code flow**, so you don't have to type a full login with a remote.

## 🎬 Advanced Playback

TetoTV gives you three playback engines so you are not stuck with one player when a device, codec, or stream behaves differently.

### Playback Engines

- **Media3**
- **MPV**
- **VLC**

### Playback Features

- Seamless next-episode playback
- Automatic source fallback
- Playback-position recovery when switching streams
- Resume tracking
- Player switching
- Subtitle controls
- Skip controls
- Custom rewind / fast-forward behavior
- Persistent per-series Dub/Sub preferences
- Improved dual-audio handling
- Commentary-track handling
- Consistent remote-friendly controls across players

When possible, TetoTV carries your previous **provider, source, release group, and Dub/Sub preference** into the next episode.
